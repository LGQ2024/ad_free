# 真机手动验证清单

当前没有连接真机或模拟器，以下项目必须在正式签名 APK 生成后完成。

- [ ] 全新安装，系统只出现 VPN 和通知授权，不出现其他运行时权限请求。
- [ ] 开启后 Android 显示 VPN 钥匙图标，前台通知可见且“停止”有效。
- [ ] 普通网页、应用 TCP/UDP 流量正常，不经过净网 TUN；仅 DNS 包进入 TUN。
- [ ] anti-AD 中的测试域名返回 `NXDOMAIN`；非规则域名由当前系统 DNS 正常解析。
- [ ] 白名单覆盖 anti-AD 公共规则中的子域和父域拦截规则。
- [ ] 日志页可将已放行域名加入自定义拦截；该域名及其子域名随后返回 `NXDOMAIN`，并可在设置页移除。
- [ ] Wi‑Fi、移动网络、飞行模式切换后状态正确并恢复解析。
- [ ] IPv4-only、IPv6-only/双栈网络分别验证。
- [ ] 上游 UDP 响应带 TC 位时能通过 TCP 53 获取完整答案。
- [ ] DNS 超时不会卡死 UI、无限创建协程或持续占用 CPU。
- [ ] 选择应用绕过后重建 VPN，该应用 DNS 不被拦截，其他应用继续受保护。
- [ ] 内存日志不超过 500 条；停止 VPN、强制停止、进程重启和设备重启后为空。
- [ ] `adb logcat` 中搜索测试域名，无任何查询域名输出。
- [ ] 应用私有目录中不存在 DNS 历史；加密状态文件不可直接读出白名单或包名。
- [ ] `adb backup`/系统云备份不包含应用数据，设备迁移不恢复私有状态。
- [ ] 未点击“立即更新”时抓包无 `anti-ad.net` 连接；点击后只有该 HTTPS 主机。
- [ ] 更新空文件、超大文件、非法 UTF-8、低有效比例和骤减列表均保留旧规则。
- [ ] 拒绝通知权限后 VPN 行为仍可控，系统前台服务界面可见运行状态。
- [ ] 与系统私有 DNS、另一 VPN 和厂商省电模式的冲突行为已记录。
